## Constraints for Optimum Infinite Orthokeratology Lenses II
Patient Spherical Error:  -0.25 to -6.00 diopters
Patient Cylinder Error:  0.00 to -1.75 diopters
Lens Diameter:  9.5 to 12.0 mm
Center Thickness:
Central Base Curve Radius:  6.50 to 10.50 mm
Optical Zone Semi Chord: 2.50 to 3.50 mm
Return Zone Width: 0.75 to 1.5 mm
Return Zone Depth: 0 to 1.0 mm
Return Zone Radius: No constraint
Landing Zone Angle: 25$^\circ$ to 50$^\circ$
Landing Zone Width: 0.5 to 2.75 mm
Peripheral Edge Curve Width: minimum 0.04 mm
Dioptric Powers: -2.00 to +2.00 diopters
Lens Material: Optimum Infinite (tisilfocon A)

### Notes:
1. ECP can specify Lens Diameter but the default is 10.5 mm.  The ECP can make adjustments to the diameter in 0.1 mm steps.
2. ECP can specify Central Zone Diameter but the default is 6.0 mm.  The ECP can make adjustments to the Central Zone diameter in 0.1 mm steps.
3. Central Zone Radius is initally selected by patient's flat K value and the patient's spherical error.  The ECP can make adjustments to the radius in 0.125 diopter steps.
4. Return Zone Depth is initally selected by patient's flat K value and the patient's spherical error.  The ECP can make adjustments to the depth in 0.01 mm steps.
5. Return Zone Width is set to 1.0 mm.
6. Landing Zone Angle is initally selected by patient's flat K value and the patient's spherical error.  The ECP can make adjustments to the angle in 1 degree steps.
7. Landing Zone Width is calculated.
8. ECP can specify Peripheral Edge Curve Depth but the default is 0.21 which generally equates to aproximately a 11.5 mm peripheral curve radius.  The ECP can make adjustments to the depth in 0.01 mm steps.
9. Peripheral Edge Curve Width is set to 0.4 mm.
10. ECP can specify Center Thickness but the default is 0.24 mm.  The ECP can make adjustments to the diameter in 0.01 mm steps.
11. Central Zone Boundary Junction Thickness Minimum is set to 0.18.
12. ECP can specify Lens Powerer but the default is +0.75 diopters.  The ECP can make adjustments to the diameter in 0.25 diopter steps.
13. Edge Thickness is set to 0.11 mm.
